## 프렉티컴 기술 개요

**서강대 AIMBA 프렉티컴 프로젝트 명: 마음다리**

본 플랫폼은 최신 AI 기술을 활용하여 아동의 감정 상태를 실시간으로 분석하고, 부모에게 전문적인 임상 소견과 개인화된 애니메이션 콘텐츠를 제공하는 종합적인 정서 지원 소통 시스템입니다.

### 핵심 가치
- 🧠 **정량적 감정 이해**: AI를 통한 객관적이고 과학적인 아동 감정 분석
- 👨‍👩‍👧‍👦 **가족 관계 강화**: 부모-자녀 간 소통 개선 및 이해 증진
- 🌱 **건강한 성장 지원**: 아동의 정서적 발달과 심리적 안정감 도모

---

## 🚀 핵심 기능

### 1. 실시간 AI 상호작용
- **음성 기반 대화**: Whisper(STT) + GEMMA3 + Zonos(TTS)를 통한 자연스러운 음성 소통
- **지능형 응답**: 아동의 감정 상태와 대화 맥락을 고려한 적응적 AI 응답
- **캐릭터 기반 인터페이스**: 친근하고 안전한 AI 캐릭터와의 교감

### 2. 고정밀 감정 분석
- **하이브리드 감정 인식**: YOLO 기반 고속 얼굴 탐지 + DeepFace 정밀 감정 분석

### 3. 전문적 임상 분석
- **AI 기반 심리 분석**: KoBERT + LoRA를 활용한 아동 심리 상태 평가
- **임상 소견 생성**: 전문가 수준의 분석 리포트 자동 생성

### 4. 맞춤형 애니메이션 콘텐츠
- **개인화 웹툰**: Stable Diffusion 기반 디즈니/픽사 스타일 캐릭터 생성
- **스토리 자동 생성**: 대화 내용을 바탕으로 한 맞춤형 시나리오 제작
- **음성 클로닝**: 제로샷 학습을 통한 아동 맞춤형 내레이션 음성 생성
- **영상 합성**: OpenCV + MoviePy를 통한 완성도 높은 애니메이션 제작

### 5. 통합 부모 대시보드
- **실시간 모니터링**: 아동의 감정 변화와 상호작용 현황 확인
- **종합 리포트**: 주기적 분석 결과 및 전문가 권장사항 제공
- **성장 기록**: 장기간 정서 발달 추이 시각화

## 🛠 기술 스택

### AI/ML 모델
| 영역 | 기술 | 역할 |
|------|------|------|
| **음성 처리** | Whisper | 음성↔텍스트 변환 |
| **음성 클로닝** | Zonos, Zero-shot Voice Cloning | 제로샷 학습을 통한 개인화된 음성 생성 |
| **대화 AI** | GEMMA3 | 상황 인식 대화 생성 및 시나리오 창작 |
| **감정 인식** | YOLO + DeepFace | 실시간 얼굴 감정 분석 |
| **텍스트 분석** | KoBERT + LoRA | 한국어 심리 상태 분석 |
| **이미지 생성** | Stable Diffusion | 고품질 애니메이션 캐릭터/배경 생성 |

### 개발 프레임워크
- **백엔드**: FastAPI (고성능 비동기 API)
- **데이터베이스**: SQLite/PostgreSQL (사용자 데이터 및 분석 결과 저장)
- **영상 처리**: OpenCV, MoviePy (실시간 영상 분석 및 콘텐츠 합성)
- **프론트엔드**: HTML, CSS, JS (참조 폴더 확인)-> PWA 기술을 통해 웹앱으로 구현 완료 (아동은 태블릿 기준 부모는 스마트폰 기준, URL:https://sogang-03e137.gitlab.io/)

## 📋 시스템 아키텍처

### 전체 워크플로우
```
아동 접속 → 캐릭터 선택 → 실시간 대화
    ↓
감정 분석 + 대화 기록 → 데이터 수집
    ↓
AI 분석 + 임상 소견 생성 → 부모 리포트
    ↓
맞춤형 웹툰 제작 → 개인화 콘텐츠 제공
```

### 주요 모듈 구성
```
📁 프로젝트 루트
├── 🤖 AI_model/           # AI 모델 및 가중치
│   ├── KoBERT/           # 텍스트 분석 모델
│   ├── RAG/              # 검색 증강 생성
│   └── Webtoon/          # 웹툰 생성 모델
├── 💾 DB/                # 데이터베이스 관리
├── 🛣 routers/           # API 엔드포인트
├── 📂 statics/           # 정적 리소스
└── ⚙️ main.py           # 메인 애플리케이션
```

## 🎨 웹툰 생성 프로세스

### 1단계: 컨텍스트 분석
- 대화 내용에서 핵심 주제 및 감정 추출
- 아동의 관심사 및 선호도 파악
- 교육적/치료적 메시지 설정

### 2단계: 비주얼 생성
- **캐릭터 디자인**: 아동의 특성을 반영한 디즈니/픽사 스타일 캐릭터
- **배경 생성**: 스토리에 적합한 환경 및 분위기 연출
- **감정 표현**: 실제 감정 분석 결과를 캐릭터 표정에 반영

### 3단계: 스토리보드 구성
- 대화 흐름을 바탕으로 한 자연스러운 서사 구조
- 교육적 메시지가 담긴 의미 있는 플롯
- 아동의 주의 집중을 위한 역동적 구성

### 4단계: 제로샷 음성 클로닝
- **개인화 내레이션**: 아동 음성 샘플 기반 제로샷 학습을 통한 맞춤형 음성 생성
- **캐릭터 보이스**: 선택된 AI 캐릭터의 고유한 목소리 합성
- **감정 반영**: 실시간 감정 분석 결과를 음성 톤과 억양에 적용
- **자연스러운 발화**: 아동의 말하기 패턴과 특성을 학습한 자연스러운 음성 구현

### 5단계: 최종 합성
- 이미지, 텍스트, 개인화된 음성을 통합한 완성된 애니메이션
- 아동의 실제 목소리로 들려주는 몰입감 있는 스토리텔링
- 다양한 디바이스에서 재생 가능한 최적화된 포맷

## 💭 프렉티컴에서의 느낀점(기술 측면)

**"처음이자 마지막, 모든 것을 담은 여정"**

ChatGPT API나 상용 솔루션을 활용하면 분명 더 빠르고 간결한 구현이 가능했을 것입니다. 하지만 이 프로젝트는 단순한 졸업작품이 아닌, **IT 개발 및 AI에 대하여 문외한이지만 열정 하나로 AIMBA 과정을 선택한 직장인들이 그동안 배운 모든 지식과 기술을 직접 체화하고 증명하는 무대**였습니다.

비전문가의 입장에서 YOLO, Stable Diffusion, LLM, RAG, LoRA, TTS, STT, 음성 클로닝 등 다양한 AI 모델을 결합하여 원하는 기능을 구현하고자 했으나, 각 모델 간의 호환성과 성능의 한계에 여러 차례 부딪히고 우여곡절을 겪었습니다. 비록 상용 API 대비 다소 낮은 성능일 수 있지만, 그 과정에서 얻은 것은 단순한 결과물을 넘어선 **AI에 대한 진정한 이해와 미래를 위한 성장**이었습니다.

이 프로젝트는 우리에게 **알파이자 오메가**입니다. 
- 학업의 시작점에서 품었던 AI에 대한 호기심이 **알파**라면,
- 바쁜 직장 생활 속에서 모든 역량을 쏟아부어 완성한 이 통합 플랫폼이 **오메가**입니다.

완벽하지 않을 수 있지만, 그 불완전함 속에서 우리는 AI 시대 속에 각자의 삶의 방향을 설정할 수 있었습니다. 
**때로는 힘들고 고된 길이 장기적으로는 가장 확실한 지름길이 되기도 한다는 것을, 몸소 체험한 소중한 여정이었습니다.**
